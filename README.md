# Temiz Yemek

Temiz Yemek icin hazirlanmis, tamamen statik ve WhatsApp odakli bir landing page projesi.

## Teknolojiler

- React
- Vite
- TypeScript
- Tailwind CSS

## Local Calistirma

```bash
npm install
npm run dev
```

Varsayilan gelistirme adresi Vite tarafinda terminalde gosterilir.

## Yapilandirma

WhatsApp numarasi ve diger iletisim bilgileri [src/constants.ts](/Users/ugurcangul/Desktop/temizyemek/src/constants.ts) icinden degistirilebilir.

## Notlar

- Proje bilerek statiktir; backend, form, odeme, sepet veya uyelik sistemi icermez.
- Ana hedef ziyaretciyi marka hakkinda bilgilendirip WhatsApp ile iletisime yonlendirmektir.
